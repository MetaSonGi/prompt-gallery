# 📚 프롬프트 갤러리 (prompt-gallery)

Prompts.chat 아이디어의 브라우저판 — 프롬프트 모음집 웹앱. 100% 브라우저에서 동작하며 외부 서버가 없다.

## 기능

- **큐레이션 프롬프트 35개 내장**: 7개 카테고리 (✍️ 글쓰기 / 💻 코딩 / 🎨 이미지 생성 / 📣 마케팅 / 📚 학습 / 💼 비즈니스 / 🏠 일상)
- **변수 치환**: 본문의 `{{변수명}}`을 자동으로 입력 칸으로 변환 → 값 입력 → 완성된 프롬프트 미리보기 → 복사
- **검색 + 카테고리 필터** (실시간)
- **복사 버튼** (클립보드) + 토스트 알림
- **즐겨찾기** (⭐, 브라우저 localStorage 저장)
- **내 프롬프트**: 직접 추가 / 수정 / 삭제 (localStorage 저장), 카테고리 지정 가능

## 사용법

1. 카테고리를 고르거나 검색창에서 프롬프트를 찾는다
2. "사용하기"를 눌러 `{{변수}}` 값을 입력한다
3. 미리보기를 확인하고 "복사하기"로 클립보드에 복사한다
4. 자주 쓰는 건 ⭐ 즐겨찾기, 직접 만든 건 "＋ 내 프롬프트"로 저장한다

## 기술

- 단일 `index.html` (CSS/JS 전부 인라인), 외부 의존성 0 (CDN 없음, 시스템 폰트만)
- 데이터 저장: `localStorage` (`pg_user`, `pg_fav`)
- GitHub Pages 배포 시 `.nojekyll` 포함

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하면 바로 사용할 수 있다.
